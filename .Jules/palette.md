## 2023-10-27 - Converting div onClick to button in AgentTimeline
**Learning:** In complex interactive components like AgentTimeline, it's common to find interactive elements structured as `div`s with an `onClick` handler, breaking keyboard accessibility and screen readers since `div` is not focusable or operable via keyboard by default. While replacing it with a semantic `<button type="button">` fixes focus/interaction, the resulting button may wrap complex layout structures (like inline-block spans or inner `div`s) which is valid in most modern browsers for interactive blocks but not strictly HTML5 standard for phrasing content. Nonetheless, the UX and accessibility gain is immediate, allowing keyboard tabbing, space/enter to interact, and `aria-expanded` state communication.
**Action:** Always scan for generic `div`s or `span`s containing `onClick` handlers. When converting them into buttons, explicitly add `w-full text-left` to preserve their block-like appearance, along with `focus-visible:outline-none focus-visible:ring-2` to restore visual focus handling natively.
