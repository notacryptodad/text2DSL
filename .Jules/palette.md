## 2024-05-18 - Interactive Table Header Accessibility in React Table
**Learning:** When using `@tanstack/react-table` (or similar headless table libraries), sortable column headers (`<th>` with `onClick` handlers) are inherently inaccessible to keyboard users and screen readers. They require `tabIndex={0}`, an `onKeyDown` listener handling "Enter" and "Space" keys to trigger the sorting logic (while safely using optional chaining `?.` to handle non-sortable columns), focus styling (like `focus-visible:ring-2`), and an `aria-sort` attribute (`ascending`, `descending`, or `none`) dynamically tied to the sort state to properly announce sorting changes.
**Action:** When implementing custom sorting logic in table components, proactively apply keyboard focusability, keydown handlers, and `aria-sort` attributes to interactive headers instead of relying solely on click events.
